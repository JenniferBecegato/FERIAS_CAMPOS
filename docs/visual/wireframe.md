# Wireframe anotado

```text
┌───────────────┬────────────────────────────────────────┬───────────────────┐
│ A Marca/menu  │ B Título                  Importar PDF │ G Detalhes        │
│               ├────────────────────────────────────────┤ colaborador       │
│ Dashboard     │ C Indicadores (4 cartões)              │ saldos + ações    │
│ Colaboradores ├────────────────────────────────────────┤ histórico         │
│ Importar PDF  │ D Controle de períodos                 ├───────────────────┤
│ Agenda        │ busca + filtros                        │ H Agenda mensal   │
│ Relatórios    │ tabela                                 │ faixas coloridas  │
│ Configurações │ paginação                              │ legenda           │
│               │                                        │                   │
│ F Admin       │                                        │                   │
└───────────────┴────────────────────────────────────────┴───────────────────┘
```

Agendamento: diálogo modal de 760 × 620, cabeçalho com colaborador e saldo, calendário de dois meses, seleção contínua início–fim, resumo do intervalo, validações e ações Cancelar/Confirmar. Primeiro clique inicia; segundo conclui; um clique posterior reinicia; as extremidades podem ser reajustadas antes da confirmação.
